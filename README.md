# Project McDonald's - A McDonald's UI/UX Landing Page


This was made using Next.JS JavaScript.

A website which is a Landing Page of a McDonald's based Business.

### The project is hosted on Vercel : [McDonald's](https://project-metaverse-beta.vercel.app/)

## ℹ️ How to use this?

1. Install the necessary dependencies
```bash
  npm install
```

2. Start the development server
```bash
  npm run dev
```
